# ByteBox

Інтернет-магазин комп'ютерів і комплектуючих на Django.

На сайті можна переглядати каталог комплектуючих з фільтрами і пошуком, купувати окремі деталі або готові
збірки ПК, а також зібрати комп'ютер самостійно в конфігураторі, який перевіряє сумісність деталей.
У блозі публікуються новини, огляди та поради зі світу комп'ютерів.

## Можливості

- Каталог процесорів, відеокарт, пам'яті та інших комплектуючих
- Готові збірки ПК для офісу, ігор і роботи з графікою
- Конфігуратор з перевіркою сумісності (сокет, тип пам'яті, форм-фактор, потужність блока живлення)
- Кошик і оформлення замовлень
- Блог зі статтями та коментарями
- Реєстрація та особистий кабінет зі збереженими збірками і замовленнями

## Технології

Python, Django, SQLite, HTML, CSS, Bootstrap 5
