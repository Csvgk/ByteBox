# ByteBox — інтернет-магазин комп'ютерів і комплектуючих

Вебзастосунок на Django: каталог комплектуючих, кошик і замовлення, готові збірки ПК,
конфігуратор «Зібрати самому» з перевіркою сумісності деталей і блог про світ комп'ютерів.

## Технології

- Python 3.13, Django 6.1, SQLite, Django ORM
- Django Templates, Django Forms / ModelForm
- Bootstrap 5 + Bootstrap Icons, власний CSS (`static/css/style.css`)
- Pillow (фото товарів і обкладинки статей), python-dotenv (секретні налаштування з `.env`)

## Запуск

```bash
git clone https://github.com/Csvgk/ByteBox.git
cd ByteBox
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
```

Відкрийте `.env` і вставте секретний ключ. Згенерувати його можна так:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Далі — база даних, адміністратор і демо-дані:

```bash
python manage.py migrate
python manage.py createsuperuser   # логін і пароль адміністратора вводите самі
python manage.py seed_shop         # 7 категорій, 13 брендів, 25 товарів
python manage.py seed_builds       # 3 готові збірки
python manage.py seed_blog         # 6 статей (автор — адміністратор)
python manage.py runserver
```

Сайт: http://127.0.0.1:8000 · адмінка: http://127.0.0.1:8000/admin/

## Структура

```text
ByteBox/
├── config/        налаштування (секрети — з .env) і головні URL
├── shop/          каталог, кошик (cart.py), замовлення
├── builder/       готові збірки і конфігуратор (compatibility.py — перевірка сумісності)
├── blog/          статті, рубрики, теги, коментарі
├── accounts/      реєстрація, вхід, особистий кабінет
├── templates/     HTML-шаблони (base.html + includes/ + папка на кожен застосунок)
└── static/        CSS і картинки-заглушки
```

## Моделі

| Застосунок | Моделі |
|---|---|
| shop | `Category`, `Brand`, `Product` (з характеристиками сумісності), `Order`, `OrderItem` |
| builder | `Build` — збірка ПК з 7 слотів (процесор, плата, пам'ять, відеокарта, накопичувач, БЖ, корпус) |
| blog | `Category`, `Tag`, `Post`, `Comment` |

## CRUD

| Запис | Create | Read | Update | Delete | Хто може |
|---|---|---|---|---|---|
| Збірка ПК | зберегти з конфігуратора | сторінка збірки, профіль | назва й опис; деталі — «Зберегти зміни» в конфігураторі | кнопка «Видалити збірку» | тільки власник |
| Коментар | форма під статтею | сторінка статті | «Редагувати» | «Видалити» | тільки автор |
| Стаття блогу | «Нова стаття» | список і сторінка статті | «Редагувати» | «Видалити» з підтвердженням | редактори (права `blog.*_post`) |
| Замовлення | оформлення з кошика | профіль, сторінка замовлення | статус — в адмінці | — | покупець бачить лише свої |
| Товари, категорії | адмінка | каталог | адмінка | адмінка | адміністратор |

## Користувачі і права доступу

- Реєстрація (ім'я, email, пароль), вхід і вихід.
- Без входу можна переглядати каталог, блог, готові ПК, користуватися кошиком і конфігуратором.
- Тільки після входу: оформлення замовлення, коментарі, збереження збірок, особистий кабінет.
- Чужі збірки, замовлення й коментарі неможливо переглянути, змінити чи видалити — сервер повертає 404.
- Створювати, редагувати й видаляти статті можуть лише користувачі з відповідними правами (інші отримують 403).

## Пошук, фільтрація, сортування

- Каталог: пошук за назвою, брендом і описом; фільтри за категорією, брендом, ціною, наявністю;
  сортування (нові, дешеві, дорогі, за назвою); пагінація.
- Блог: пошук, фільтр за рубрикою і тегом, пагінація.
- Готові ПК: фільтр за призначенням (офіс, ігри, робота з графікою).
- Конфігуратор: показує лише деталі, сумісні з уже обраними.

## Додатково

- Особистий кабінет (замовлення і збережені збірки)
- Завантаження зображень (товари, статті)
- Коментарі
- Перевірка сумісності деталей: сокет, тип пам'яті, форм-фактор, вбудована графіка, потужність блока живлення
- Адаптивний дизайн (від 375 px)

## Безпека

Секретний ключ і режим налагодження зберігаються у файлі `.env`, який не потрапляє в Git
(у репозиторії є лише шаблон `.env.example`). Паролів у коді немає.

Ціни і наявність товарів — демонстраційні.
